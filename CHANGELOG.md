# Changelog

All notable changes to ProfileFleet are documented here. The project follows
Semantic Versioning while the public API is in active `0.x` development.

## 0.1.0 — 2026-09-04

- Add persistent browser profiles with fixed identity fields.
- Add exclusive renewable leases, capacity control, idle shutdown, and request
  idempotency.
- Add owner-token profile locks and orphan browser adoption.
- Add loopback-only Hono daemon, bearer authentication, origin checks, and SSE
  lifecycle events.
- Add framework-neutral TypeScript client and Playwright connection helper.
- Add React hooks, components, and a built-in Vite console.
- Add CloakBrowser and fake engine adapters.
- Add cross-platform CI, package consumer smoke tests, bilingual documentation,
  security guidance, and acceptable-use policy.
